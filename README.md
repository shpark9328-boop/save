# save

달력이 포함된 개인 홈페이지입니다. 빌드 과정 없이 순수 HTML/CSS/JavaScript로 만들어졌습니다.

## 바로 보기

`index.html` 파일을 브라우저로 열면 됩니다.

```bash
# 또는 간단한 로컬 서버로 실행
npx serve .
```

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 구조 (히어로 · 달력 · 소개 · 문의) |
| `styles.css` | 디자인 토큰, 반응형 레이아웃, 라이트/다크 테마 |
| `app.js` | 월간 달력 렌더링, 일정 추가/삭제, 테마 전환 |

## 기능

- **월간 달력** — 이전/다음 달 이동, `오늘` 버튼, 오늘 날짜 강조, 주말 색 구분
- **일정 관리** — 날짜를 클릭해 일정을 추가·삭제, 일정이 있는 날은 점으로 표시
- **다가오는 일정** — 오늘 이후 일정 5개를 D-day와 함께 표시
- **자동 저장** — 일정은 브라우저 `localStorage`에 저장 (서버 없음)
- **다크 모드** — 시스템 설정을 따르고, 헤더의 버튼으로 직접 전환 가능
- **반응형** — 모바일에서도 가로 스크롤 없이 동작

## 커스터마이징

- 사이트 이름: `index.html`의 `.logo-text`와 `<title>`
- 색상: `styles.css` 상단 `:root`의 `--accent` 등 토큰 값
- 연락처: `index.html`의 `#contact` 섹션 (현재는 예시 값)

## 배포

정적 파일이므로 GitHub Pages, Netlify, Vercel 등에 그대로 올릴 수 있습니다.
GitHub Pages는 저장소 Settings → Pages에서 브랜치를 선택하면 됩니다.
